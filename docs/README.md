# Pinology documentation

Experimental ARM DSM virtualization with a custom QEMU board model. Start with
the installation guide for your host; do not use the only copy of valuable data.

| Design and compatibility | [Architecture](en/architecture.md) | [Архитектура](ru/architecture.md) |
| Diagnostics and recovery | [Troubleshooting](en/troubleshooting.md) | [Диагностика](ru/troubleshooting.md) |

The guides describe the same feature set in both languages. CLI option names and
configuration keys are identical. The repository is source-only: no DSM firmware,
user disks, credentials, prebuilt emulator or notarized application is included.
