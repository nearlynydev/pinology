# Community conduct

Be respectful and constructive. Technical disagreement is welcome; harassment,
discrimination, threats, doxxing and publication of private information are not.
Do not demand help with stolen serial numbers, private device dumps or access
to somebody else's systems. Discuss limitations honestly and credit others.

These expectations apply to issues, pull requests, discussions and other
project spaces. Maintainers may edit/remove harmful content, close disruptive
threads or restrict participation. Report abuse privately using GitHub's
reporting tools. For software vulnerabilities use [SECURITY.md](SECURITY.md).
